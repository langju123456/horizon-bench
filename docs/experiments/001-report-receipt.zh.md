# D001：年报提交回执实验

固定输入是宁德时代 FY2025 经营活动产生的现金流量净额工作稿：全年 `133219982`、第四季 `52559552`，单位人民币千元；来源为[巨潮资讯年报 PDF](https://static.cninfo.com.cn/finalpage/2026-03-09/1225002666.PDF)印刷页 11/12。它是已审阅的公开开发事实，不是模型取数、检索或财务正确性的评测。

每格都使用相同 `task_id`、payload、版本 `catl-fy2025-cfo-v1` 与内容摘要。客户端 SQLite 保存意图及状态；另一个 SQLite 是收件箱，代表独立外部效果。收件箱只按幂等键接受完全相同的 `(task_id, payload, version, digest)`；同键异参报错。

预登记矩阵为四种策略（猜测成功、等待人工、用新键重试、查询原键后对账）乘三种故障（正常确认、写入前请求丢失、写入后回执丢失）。后两种界面对策略都是超时；策略代码不接收故障参数。正常确认和写入前丢失由工具模拟；写入后回执丢失在子进程成功写入收件 SQLite 后调用 `SIGKILL`，父进程观察退出码并以新子进程恢复。

独立判定器固定使用上述公开任务的预期 payload、版本和摘要 `eedd9faa…a5aec` 作 oracle；它把同一 `task_id` 的所有收件作为分母，并重算每条内容摘要。只有「恰有一份预期内容、版本和摘要，且本地状态为 completed」才通过。因此它不承诺 exactly-once：新键重试会在回执丢失时制造两份有效外部效果；猜测成功会在请求未送达时错误宣布完成；等待人工是诚实暂停而不是无人值守成功。原始每格稳定 JSON、判据和复跑命令随实验输出放在 `reports/receipt-experiment/`；SQLite/WAL 仅是运行期 scratch，不纳入 Git。
